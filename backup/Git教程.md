# 1.常用命令
## 1.1 克隆仓库

```bash
git clone <repository_url>
```

## 1.2 查看状态

```bash
git status
```
## 1.3 添加文件到暂存区

```bash
git add <file_name>
```
## 1.4 提交更改

```bash
git commit -m "commit message"
```
## 1.5 推送到远程仓库

```bash
git push origin <branch_name>
```
## 1.6 拉取远程仓库的更改

```bash
git pull origin <branch_name>
```
## 1.7 创建分支

```bash
git branch <branch_name>
```
## 1.8 切换分支

```bash
git checkout <branch_name>
```
## 1.9 合并分支

```bash
git merge <branch_name>
```
## 1.10 查看提交历史

```bash
git log
```
## 1.11 删除分支

```bash
git branch -d <branch_name>
```
## 1.12 查看远程仓库

```bash
git remote -v
```
## 1.13 添加远程仓库

```bash
git remote add <remote_name> <repository_url>
```
## 1.14 删除远程仓库

```bash
git remote remove <remote_name>
```
## 1.15 查看分支

```bash
git branch
```
## 1.16 查看远程分支

```bash
git branch -r
```
## 1.17 查看所有分支

```bash
git branch -a
```
## 1.18 重命名分支

```bash
git branch -m <old_branch_name> <new_branch_name>
```
